# Historical demonstration

The `assets/`, `attack/` and `infra/` trees predate TrustFall and demonstrate Azure policy/OIDC risks. They contain deliberately vulnerable templates, synthetic role/principal identifiers, placeholder subscription parameters, and operational walkthrough text. Review found no embedded live credential values. Do not deploy these templates outside an isolated research subscription.

Their former GitHub workflow definitions are preserved here with a `.disabled` suffix so GitHub cannot execute them. Historical references to `azurekid/policy-as-code` are provenance, not TrustFall repository identity. These trees are not built, tested, packaged, or supported as part of TrustFall releases.
