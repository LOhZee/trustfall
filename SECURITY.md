# Security policy

Please report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Do not include live tokens, cloud identifiers, internal reports, or exploit data in a public issue. Include the affected version/digest, a minimal reproduction with synthetic data, and the security impact.

Supported releases are the latest minor release of the current major version. Security fixes may be backported when exploitation affects a widely deployed older major. Release archives, checksums and GitHub attestations are published together; consumers should verify all three and pin GHCR by digest.

TrustFall is an assessment tool, not a containment boundary. A compromised runner can mislead or replace it. Results must be interpreted according to their evidence classification and documented limitations.
